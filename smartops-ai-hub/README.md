# SmartOps AI Hub - Sistema Inteligente de Automatización Híbrida

Este es un proyecto completo de ingeniería de software estructurado para demostrar el dominio de arquitecturas de datos híbridas (**SQL + NoSQL**), orquestación de inteligencia artificial asíncrona y desarrollo full-stack moderno.

## 🚀 Arquitectura y Tecnologías Utilizadas

- **Backend:** Python con Django 4.2 utilizando su patrón arquitectónico para construir APIs limpias y desacopladas.
- **Base de Datos Relacional (SQL):** SQLite/PostgreSQL gestionado por el ORM de Django para transacciones críticas, integridad referencial y auditorías estructuradas.
- **Base de Datos NoSQL (MongoDB):** Integrado a través de `PyMongo` para logs polimórficos de alta velocidad y almacenamiento de payloads analíticos profundos de IA.
- **Frontend Avanzado:** HTML5 semántico, CSS3 estructurado con layouts modernos (Grid/Flexbox) y JavaScript Vanilla asíncrono (**Fetch API**) para el manejo reactivo del DOM sin recargas de página.
